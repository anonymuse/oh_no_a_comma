# Repository guidance

This repository is an anonymized Vite + React + TypeScript demo for a location-filter normalization walkthrough. Use synthetic data only. Do not add real company names, domains, email addresses, screenshots, job listings, logos, or identifiable employer data.

Keep the demo small, polished, deterministic, and frontend-focused. Prefer framework-agnostic utilities under `src/lib/` and reusable React components under `src/components/`.
