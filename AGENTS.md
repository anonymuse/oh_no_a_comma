# Repository guidance

This repository is an anonymized Vite + React + TypeScript demo for a README-driven locality-normalization case study. Use synthetic data only. Do not add real company names, domains, email addresses, screenshots, job listings, logos, ATS vendor names, or identifiable employer data.

Keep the demo small, polished, deterministic, and frontend-focused. Prefer framework-agnostic location utilities under `src/lib/location/` and reusable React components under `src/components/`.

Generative AI may be discussed as an assistive review tool, but it must not be required for runtime, tests, CI, or deterministic validation.
